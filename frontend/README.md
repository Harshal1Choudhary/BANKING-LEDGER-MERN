# Frontend (React)

The React app for the MERN Banking Ledger project will live here.

Planned setup (when the backend course is complete):

```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm install axios react-router-dom
```

Planned pages:
- Login / Register
- Dashboard (accounts + balances)
- Transfer (send money)
- Transaction history (ledger view)

The frontend will consume the backend REST API (see `../backend`).
